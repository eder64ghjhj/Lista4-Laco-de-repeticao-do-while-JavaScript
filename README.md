# 🔄 Lista 4 — Laço de Repetição Do-While em JavaScript

Série de exercícios práticos com estrutura de repetição `do-while` em JavaScript, explorando a diferença entre while e do-while e casos de uso específicos.

## 📚 Conteúdo

- Estrutura `do-while` e sua diferença em relação ao `while`
- Garantia de execução mínima de uma iteração
- Validação de entrada do usuário com do-while
- Exercícios práticos com lógica de repetição

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
